# 글자 크기(큰글씨)

설정 > 글자 크기에서 앱의 글자 크기를 고른다. iPhone 전체 설정을 바꾸지 않고 이 앱만 크게 볼 수 있다.

| 선택 | 동작 |
|---|---|
| 기본 | iPhone의 글자 크기 설정을 따른다 |
| 크게 | 표준 크기 중 가장 큰 단계(본문 23pt) 이상으로 보여 준다 |
| 아주 크게 | 손쉬운 사용 2단계(본문 33pt) 이상으로 보여 준다 |

- iPhone 설정이 더 크면 그 크기를 그대로 쓴다. 앱이 글자를 더 작게 만드는 일은 없다(`AppTextSize.step(systemStep:)`).
- 선택은 `UserDefaults`의 `appTextSize`에 저장한다. 계정이나 서버와 무관하며 기기별 설정이다.
- 적용은 창(window) 단위다. `AppTextSizeController`가 앱 창과 잠금 화면 창의 글자 크기 trait을 덮어쓰므로,
  UIKit·SwiftUI 화면과 시트가 모두 같은 크기를 따른다. 화면마다 따로 처리하지 않는다.
- iPhone의 글자 크기가 바뀌면 다시 계산한다.

## 큰 글자에서 바뀌는 배치

- 일기 쓰기: 날짜 카드의 "날짜 변경" 버튼이 날짜 아래로, 현재 날씨가 기분·날씨 버튼 아래로 내려간다.
  아래 막대(사진·기분·날씨)는 세 버튼이 폭을 나눠 쓰므로 표준 최대 크기까지만 커진다.
- 일기 목록: 기존의 큰 글자 배치(세로 쌓기)를 그대로 쓴다.
- 캘린더 날짜 칸: 일곱 칸을 유지하려고 표준 최대 크기까지만 커진다.
- 여정: 달·작성 개수 글자가 함께 커진다.

## 확인

`AppTextSizeTests`가 크기 계산·저장을 검증한다. 시뮬레이터에서 "아주 크게"로 설정·목록·쓰기·읽기·캘린더·여정 화면을 확인했다.
잠금 화면, 알림 설정, 휴지통, 로그인, 온보딩, 연도 보기 시트는 큰 글자로 따로 확인하지 않았다.
