# 일기 알림

설정 › 알림에서 일기 쓸 시간과 요일을 정하면 그 시간에 일기를 쓰도록 알린다(목업 17번).

## 동작

- 알림 받기를 켤 때 처음 한 번 권한을 묻는다. 거부했거나 iPhone 설정에서 꺼져 있으면 화면에 안내와 설정 열기 버튼을 보여 준다.
- 시간은 휠로 정한다. 반복은 iOS 미리 알림처럼 "반복" 행의 메뉴(매일·평일·주말)와 그 아래 일~토 버튼으로 정한다. 바꾸는 즉시 저장·예약하고 "다음 알림"을 보여 준다.
- "오늘 일기를 쓰면 그날은 알리지 않기"(기본 켬): 오늘 날짜의 일기(휴지통 제외)가 생기면 그날 알림을 뺀다.
  휴지통으로 옮기면 다시 넣는다.
- 알림 문구는 날마다 바뀐다(7가지).
- 끄면 예약만 지우고 시간·요일은 남겨 둔다(기존에는 설정까지 지웠다).

## 예약 방식

반복 알림은 특정 하루만 건너뛸 수 없어서, 오늘부터 28일 안의 선택한 요일마다 한 번씩 예약한다(iOS 최대 64개).
앱이 활성화될 때, 설정을 바꿀 때, 오늘 일기가 생기거나 없어질 때 다시 예약한다. 식별자는 `diary-reminder-yyyy-MM-dd`이며,
이전 버전이 만든 요일별 반복 알림(`1`~`7`)도 함께 지운다. 앱을 4주 넘게 열지 않으면 알림이 멈춘다.

오늘 일기 여부는 로그인한 사용자의 일기 구독(`UserDiaryFeed`)으로 알고, 오늘 날짜만 UserDefaults(`ReminderWrittenDay`)에 남긴다.

## 저장과 기존 사용자

이전 `NotificationVC`의 키(`isSwitchOn`, `selectedTime`, `selectedDays`: 일요일부터 7개 Bool)를 그대로 읽고 쓰므로
업데이트 전 설정이 유지된다. 새 키는 `ReminderSkipWhenWritten`, `ReminderWrittenDay`뿐이다.

## 검증

- `DiaryReminderTests` 13개: 28일 예약, 지난 시간·요일 제외, 오늘 일기 건너뛰기·휴지통 복귀, 권한 없을 때, 이전 설정 읽기, 화면 상태.
- 시뮬레이터: 권한 요청, 요일·평일 버튼과 요약, 시간 변경 후 다음 알림 문구, 예약 개수(월~토 23개), 2분 뒤 알림 실제 도착을 확인했다.
- 알림을 눌렀을 때 작성 화면을 바로 여는 동작은 없다(작성 화면 작업 후 추가). 실기기 확인은 하지 않았다.
  기존 `NotificationVC`와 셀들은 참조가 없으며 확인 후 삭제한다.
